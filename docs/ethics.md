# Ethics and scope of use

AuthBench is a **defensive** research benchmark. It measures how well existing anomaly-detection
approaches perform at flagging authentication events already known to be malicious (LANL's
red-team dataset). It does not implement, and is not intended to inform, any offensive
capability — the models here rank *already-collected* logs, they do not generate attacks, evade
defenses, or interact with live systems.

## Data

- **LANL** (Kent, 2015): de-identified, publicly released for research, citation required
  (see `README.md`). No real usernames, hostnames, or organizational identity are exposed —
  all identifiers in the public release are already anonymized/synthetic tokens.
- **CERT Insider Threat** (SEI/CMU): fully **synthetic** data, generated for research use under
  the SEI's terms; used only for a generalization check, never as a primary result.
- Neither dataset is redistributed by this repository — only the download scripts
  (`authbench.ingest.download`) are, per each dataset's own license (Apache 2.0 covers this
  repository's code only, see `LICENSE`).

## No real personal data

No component of this project processes real, identifiable personal data. The demo sample
(`data/demo/`) is entirely synthetic, generated by `scripts/generate_demo_data.py` with a fixed
seed — no real user, machine, or organization is represented.

## Intended use

Security research, benchmarking, and education. Not intended for deployment as a production
detection system without independent validation on the target environment — see
`docs/limitations.md` for the threats to validity this implies (a single 2015 enterprise
network, partial ground truth, no adaptive adversary).
